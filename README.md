# Five Nights at Chami v1.5 — Paranoia

Upload `index.html`, `style.css`, `game.js`, `CHANGELOG.md`, and optional `assets/faces/*.jpg` to a GitHub Pages repository root. Enable Pages on the `main` branch.

**Features:** Two-floor fictional school, movement, flashlight, cameras, chase AI, hiding, night progression, jump scares, local-save slip shop, confetti victory, random events, camera outages, batteries, custom night, achievements.

**Custom Night:** Beat Night 5 to unlock. Select AI levels 0–20 for four enemies.

**Controls:** WASD move, mouse look, Shift run, F flashlight, C cameras, E hide, Escape pause. Touch controls available on mobile.

**Caveats:** Requires internet for the Three.js CDN. Real staff photos are not bundled; add authorized images in `assets/faces/`. This is a prototype, not a 1:1 school replica. Polls are not implemented. Local browser storage is not cheat-proof.

## v1.6 visuals
